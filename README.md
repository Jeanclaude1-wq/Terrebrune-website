# Terrebrune – Hotel Website

## Project Overview

Terrebrune is a hotel website developed as a university project during my Bachelor of Computer Science studies.

The website provides visitors with information about the hotel, its facilities, services, and accommodation through a simple and user-friendly interface.

## Features

- Homepage introducing Terrebrune Hotel.
- Multiple pages presenting the hotel and its facilities.
- Information about hotel services and offerings.
- Image galleries and visual content.
- Navigation between website pages.
- Interactive elements using JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

The project includes:
- HTML files for website pages.
- CSS files for styling and layout.
- JavaScript files for interactive functionality.
- Images and visual assets used throughout the website.
